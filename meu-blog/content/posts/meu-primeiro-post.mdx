# Bem-vindo ao meu novo blog!

Este é o primeiro artigo escrito em **MDX**. O uso de Markdown com React permite renderizar tanto texto formatado quanto componentes interativos diretamente no conteúdo.

## Por que utilizar SSG e Server Components?

1. **Performance Absoluta:** O HTML é pré-renderizado em tempo de _build_.
2. **SEO Nativo:** Motores de busca indexam a página sem precisar esperar pela execução de client-side scripts.
3. **Zero JS Desnecessário:** Nenhum parser de Markdown é enviado para o cliente.

```javascript
// Exemplo de código limpo em TypeScript
const blog = {
  framework: "Next.js",
  performance: 100,
  cleanCode: true,
};
console.log(`Blog rodando com ${blog.framework}!`);
```
